# ✨ Particles — Personal Invitation Page

Интерактивная страница-визитка с анимированным фоном из частиц. Проект создан для привлечения клиентов и удобной навигации по моим социальным сетям.

## 🌟 Особенности проекта

* **Интерактивный фон**: Реализация динамических частиц на чистом **JavaScript** (или с использованием `particles.js`), которые реагируют на движение мыши.
* **Минималистичный дизайн**: Акцент на контенте и кнопках призыва к действию (CTA).
* **Адаптивность**: Страница идеально отображается как на мониторах, так и на экранах мобильных устройств.
* **Glassmorphism**: Использование эффекта матового стекла для карточек и кнопок, что придает интерфейсу современный вид.

## 🛠 Технологический стек

* **HTML5**: Семантическая структура страницы.
* **CSS3**: 
    * Flexbox для центрирования контента.
    * Кастомные анимации и градиенты.
    * Медиа-запросы для мобильной версии.
* **Vanilla JavaScript**: Логика работы частиц, обработка событий мыши и плавные появления элементов.
